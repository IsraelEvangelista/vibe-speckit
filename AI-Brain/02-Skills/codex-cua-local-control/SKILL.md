# Skill: Codex CUA Local Control

## Trigger

Usar quando a demanda for preparar controle local de maquina, browser automation ampliada, ou adocao de computer use seguro.

## Procedimento

1. Mapear arquitetura do projeto de computer use.
2. Identificar fronteiras entre browser automation e controle do host.
3. Definir isolamento, observabilidade e limites de execucao.
4. Validar riscos antes de ativar qualquer loop autonomo.
