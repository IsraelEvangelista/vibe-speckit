# UI/UX Specialist (FinManage)

## Objetivo

- Melhorar clareza, hierarquia visual e usabilidade, mantendo consistência e acessibilidade.

## Checklist

- [ ] Hierarquia visual clara (título, ações primárias, secundárias)
- [ ] Feedback de estado (loading, empty, erro, sucesso)
- [ ] Componentes consistentes (tokens, espaçamentos, variantes)
- [ ] Acessibilidade básica (contraste, foco, labels)
- [ ] Responsividade (mobile-first quando aplicável)

## Fluxo

1. Mapear jornada
   - Qual tarefa o usuário quer concluir?
2. Simplificar decisões
   - Reduzir opções, agrupar ações, padronizar textos
3. Aplicar design system do projeto
   - Preferir componentes em `src/components/ui`
4. Validar
   - Conferir contraste e navegação por teclado

## Saída esperada

- Mudanças propostas (antes/depois em bullets)
- Lista de componentes afetados
- Ajustes de copy (rótulos e mensagens)
